band-ticket — バンド向けライブ取り置き予約

概要

個人バンド・インディーズ向けに、ライブの取り置き・前売り予約を受け付けるサービス。 バンドが公演ページを作り、URL を SNS で告知するだけで、ファンが名前とメールアドレスで取り置き予約できる。 主催者は予約一覧と「お目当てバンド別」の枚数(対バン時のチケットバック計算用)を確認できる。

自作中のチケット予約システム(Next.js + Supabase + Resend + Cloudflare Pages)の構成を流用し、 1バンド専用ではなく複数バンドが登録して使える汎用形を前提に設計している。

想定ユーザー

  • 主催者: 個人バンド・インディーズバンドのメンバー、自主企画イベントの主催者
    • 今は DM・Google フォーム・スプレッドシートで取り置きを管理していて手間/ミスが多い
  • 予約者: そのバンドのファン(スマホから SNS 経由でアクセス)

MVP の機能

  • 公演一覧(トップ)
  • 公演詳細 + 取り置き予約フォーム(名前・メール・枚数・お目当てバンド・メッセージ)
  • 予約上限(残り枚数)チェック
  • 予約完了画面
  • 予約確認メール送信の骨格(現状はコンソール出力のモック)
  • 主催者メニュー: 自バンドの公演一覧と予約数、公演作成フォーム
  • 主催者向け予約一覧 + お目当てバンド別集計
  • 主催者ログイン(Supabase Auth)とバンド単位のデータ分離(RLS)
  • 予約キャンセル(予約者のメール内リンクから)
  • 予約一覧の CSV 出力 / 当日受付用の印刷レイアウト
  • Supabase / Resend 実装への差し替え

技術構成

項目 雛形 本実装予定
フロント/サーバー Next.js 15 (App Router, Server Actions), TypeScript 同左
DB インメモリ(src/lib/repository.ts、再起動でリセット) Supabase(supabase/schema.sql が定義案)
メール コンソール出力モック(src/lib/mailer.ts) Resend
ホスティング ローカルのみ Cloudflare Pages/Workers(@opennextjs/cloudflare 想定)

差し替えポイントは Repository / Mailer インターフェースにまとめてあり、画面側は変更不要の想定。

起動方法

npm install
npm run dev     # http://localhost:3000
npm run build   # 本番ビルド確認
  • / 公演一覧 → 公演を選んで予約
  • /dashboard 主催者メニュー(雛形では認証なし。?band=band-2 でデモ用にバンド切り替え)
  • 予約すると確認メールの内容がサーバーのコンソールに [mock-mail] として出力される

収益化案

  1. フリーミアム + 月額: 無料プランは「同時公開できる公演数 2件・予約 月100枚まで」。 有料(月 500〜980円)で公演数・予約数無制限、CSV 出力、確認メールのカスタム、独自ロゴ表示。
  2. 予約件数課金: 月額が重いライト層向けに「無料枠超過分は 1予約 10〜20円」の従量プラン。
  3. 将来: 前売りのオンライン決済(Stripe Connect)を入れ、決済手数料に数%上乗せ。 ※ 当面は「当日精算の取り置き」に絞り、決済まわりの法務・手数料負担を避ける。

集客案

  • 予約ページのフッターに「band-ticket で予約ページを作る」リンク(ファン経由で他バンドへ波及)
  • 対バン企画: 主催バンドが共演バンドを招待できる機能 → 1公演で複数バンドに露出
  • X(Twitter)/ Instagram でのバンドマン向け発信(「取り置き DM 管理から解放」系の比較投稿)
  • ライブハウス・ブッキング担当への紹介(ハコ単位で共演バンドに勧めてもらう)
  • 「ライブ 取り置き フォーム 作り方」等の SEO 記事

次にやること

  1. Supabase プロジェクト作成 → schema.sql 適用、SupabaseRepository 実装
  2. Supabase Auth で主催者ログイン、bands.owner_id に基づく RLS 設定
  3. 予約作成を RPC(残数チェック + insert を1トランザクション)に移行して同時予約の超過を防ぐ
  4. ResendMailer 実装(送信元ドメイン認証)、主催者への新規予約通知メール
  5. 予約キャンセル用の署名付きリンク
  6. Cloudflare Pages へのデプロイ設定(@opennextjs/cloudflare)
  7. 既存の自作チケット予約システムから流用できるコンポーネントの洗い出し
