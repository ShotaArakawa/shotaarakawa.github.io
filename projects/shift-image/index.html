シフト画像メーカー(shift-image)

コンカフェ・ガールズバー等の「本日の出勤」「週間シフト」画像を、キャストにチェックを入れるだけで作れるブラウザツール。 画像生成はすべてブラウザの Canvas で行い、データも端末内(localStorage)に保存するため、サーバー費用はほぼゼロ。

起動方法

npm install
npm run dev      # http://localhost:5173
npm run build    # 型チェック + 本番ビルド(dist/)

概要

  • キャストを登録し、日ごとに出勤者と時間(開始〜終了/LAST)を入れる
  • 日別(本日の出勤)・週間(7日分)の2種類の画像を 1080×1350px(Instagram 縦長)でプレビュー
  • テンプレ切り替え(ポップ / シンプル / ネオン)と、背景・アクセント・文字色・フォントの調整
  • PNG でダウンロードしてそのまま X / Instagram に投稿できる

想定ユーザー

  • コンカフェ・メイドカフェ・ガールズバー・バーなどの店長/SNS担当(毎日シフト画像を手作業で作っている人)
  • 小規模なイベントバー・アイドル対バンなど「今日いる人」を告知したい運営

MVP の機能リスト

機能 雛形の状態
キャスト登録(名前・色・一言コメント) ✅ 実装(追加・編集・削除。削除時はシフトも削除)
日別の出勤入力(チェック+開始・終了時刻) ✅ 実装(前日コピー付き)
画像プレビュー(日別 / 週間) ✅ Canvas でリアルタイム描画
画像ダウンロード ✅ PNG
テンプレ切り替え・色・フォント調整 ✅ 3テンプレ、3色、3フォント
無料版の透かし / 有料版で除去 ✅ モック(チェックボックスで切替。課金処理なし)
データ保存 ✅ localStorage(StateStore インターフェースで差し替え可能)

構成

  • Vite + React 18 + TypeScript(依存は最小限、CSS は素の CSS)
  • src/lib/render.ts … Canvas 描画(テンプレごとの装飾は背景・見出し・行ボックスに集約)
  • src/lib/templates.ts … テンプレ定義・フォント・画像サイズ
  • src/lib/storage.ts … 保存先(localStorage)とサンプルデータ
  • src/components/ … 入力パネル・プレビュー
  • ホスティング想定: Cloudflare Pages(静的配信のみで動く)

収益化案

  • 無料: 全機能利用可、ただし画像に透かし+「made with」表記
  • 有料(月額 300〜500円目安): 透かし除去、PRO テンプレ(ネオン等)の解放、店舗ロゴ画像の差し込み、季節テンプレ
  • 買い切りテンプレ: イベント用(誕生日・周年・ハロウィン等)テンプレを単品販売
  • 将来: 複数端末同期(Supabase)や複数店舗管理を上位プランに

集客案

  • 無料版の透かし・「made with」表記そのものを広告にする(投稿画像経由の認知)
  • 「コンカフェ シフト 画像 作り方」「出勤表 テンプレ」などで SEO 記事+テンプレ一覧ページ
  • X でコンカフェ店舗アカウントに使用例を見せる/テンプレ配布キャンペーン
  • 業界の求人・ポータルサイトや、店舗向け SaaS(予約・POS)との相互紹介

次にやること

  1. Web フォント(M PLUS Rounded 1c 等)を同梱し、document.fonts.load 後に描画して端末差をなくす
  2. 週間画像で出勤者が多い日の折り返し表示(現状は1行に縮小して収めている)
  3. 店舗ロゴ・背景画像のアップロード(ブラウザ内で完結)
  4. テンプレ追加と、テンプレの位置・サイズ調整 UI(縦横比 1:1 / 9:16 の切り替えも)
  5. 有料プランの実装(Stripe 等。透かし除去を課金状態で判定)
  6. 必要になったら Supabase で複数端末同期(StateStore を差し替え)
  7. Cloudflare Pages へのデプロイ設定
